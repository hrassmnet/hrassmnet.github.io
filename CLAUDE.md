# Project instructions

## Read first, every session

At the start of every session, read `SourceMaterial/Design.md` in full before
doing any work. It is the authoritative brief for this site — the design system,
page specs, motion rules, hard don'ts, and technical constraints all live there.
When it conflicts with a general instinct about "good web design", it wins.

## Frontend/UI work

Always invoke the `frontend-design` skill before doing any UI work in this repo — building or restyling components, pages, layouts, or Astro/Tailwind templates. Use it to pick a deliberate aesthetic direction and avoid generic "AI slop" styling; don't skip it for small tweaks.
